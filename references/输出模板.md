# 输出模板

> 三张表的完整字段模板（含「风险等级」「优先级」）。AI 在对应阶段套用并填入用户确认的信息。
> 完整虚拟企业示例见 [案例示范.md](案例示范.md)，无思路时可直接调出参考。

## 字段取值统一说明

- 相关方类别 = 外部 / 内部
- 需求来源 = 法规强制 / 合同顾客 / 隐含期望
- 监视与评审频率 = 月度 / 季度 / 半年 / 年度 / 事件驱动（法规变更、顾客投诉等触发）
- 风险等级 = 高 / 中 / 低（未满足时对体系/顾客/法规的潜在影响）
- 优先级 = 高 / 中 / 低（或 P0 / P1 / P2，用于排序跟进资源）
- 当前满足状态（表2）= 满足 / 部分满足 / 不满足 / 未识别
- 跟进状态（表2）= 建议 / 已启动 / 进行中 / 已完成
- 评审结论（表3）= 满足 / 需关注 / 不满足 / 待改进
