# 案例示范 · 虚拟企业完整三表

> **用途**：当用户（体系工程师）毫无思路、不知从何下手时，AI 可说「先给您看一个同类企业的完整示例」，然后展示本文件，再回到「1~2 问/轮」的引导节奏。
> **性质**：本企业为**虚拟示例**（星跃汽车零部件），仅用于演示模板填法，非真实企业事实，不得作为任何企业的策划基线。

---

## 虚拟企业画像（演示用）

| 项目 | 内容 |
|------|------|
| 企业名称 | 星跃汽车零部件（上海）有限公司（虚拟） |
| 行业 / 产品 | 新能源汽车零部件：电机壳体、电池托盘、减速器壳体（铝合金压铸 + 机加 + 表面处理） |
| 供应链定位 | Tier-2 供应商，顾客为 Tier-1 总成厂 |
| 认证 | IATF 16949:2016、ISO 14001（虚拟） |
| 出口 | 部分产品出口欧洲（涉及海关 / CE） |
| 现场 | 上海嘉定单一现场；表面处理工序产生危废 |

**覆盖的相关方（共 10 类）**：2 个顾客（Tier1）、1 个外部供方、3 个监管机构（环保/市场监管/海关）、1 个认证机构、员工、股东/银行、周边社区。
