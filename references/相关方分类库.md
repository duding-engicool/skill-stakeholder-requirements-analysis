# 相关方分类库（AI 分类与需求推断依据）

> AI 在 Step 2 结构化分析时，据此判定相关方类型、推断遗漏项与可能需求。所有推断结果须标注「AI 推断 · 待确认」，不得伪装成用户已确认事实。

---

## 一、按内外部分类

### 外部相关方

| 类别 | 典型代表 | 常见需求/期望（推断用） |
|------|---------|----------------------|
| 顾客 | OEM、Tier-1、经销商、终端消费者 | 准时交付、质量/PPM、CSR 符合、审核通过、价格、服务响应 |
| 外部供方/外包方 | 原材料/零部件供应商、物流、外包工序 | 稳定订单、清晰要求、及时付款、公平评估 |
| 监管机构 | 市场监管、环保、海关、安监、税务 | 合规、证照、上报、达标排放、如实申报 |
| 认证/审核机构 | 认证机构、二方/三方审核 | 体系有效、证据充分、纠正及时 |
| 周边社区/公众 | 居民、媒体、NGO | 无污染、安全、就业、透明 |
| 股东/金融 | 股东、银行 | 盈利、风险可控、合规、信息披露 |
| **竞争对手（重要·第一梯队）** | 同业企业、潜在进入者、替代技术方 | 竞争态势、技术/产能动向、价格与交期变化（用于识别风险与机遇） |
| 其他 | 行业协会 | 标准参与、公平竞争 |

### 内部相关方

| 类别 | 典型代表 | 常见需求/期望 |
|------|---------|--------------|
| 员工 | 操作工、技术、职能人员 | 安全、培训、薪酬公平、参与、清晰职责 |
| 管理层/所有者 | 总经理、董事会 | 战略达成、合规、效率、持续改进 |
| 职能部门 | 研发、生产、质量、采购、HR | 资源、协同、信息畅通、权责清晰 |

## 二、IATF 16949 特别关注（推断补充项）

- **顾客特定要求（CSR）**：4.3.2 强制纳入，凡汽车供应链必查（如大众、通用、福特、比亚迪等各自 CSR）。
- **产品安全相关方**：监管（产品安全法规）、顾客（安全件要求）、员工（安全作业）。
- **出口场景**：海关、进口国监管（如 EPA、CE）。
- **制造现场**：环保（危废）、安监（职业健康）、社区。
- **竞争对手（重要外部相关方 · 第一梯队，不可降级为间接）**：管理体系与经营业务结合的关键落点。其动向（新产能、技术迭代、价格/交期变化、并购）是 ISO 9001:2015「4.1 组织环境 → 6.1 风险与机遇」的核心输入，须作为独立、重要相关方直接纳入分析，识别其带来的风险与机遇；其"期望"非合规义务，而是需监视的竞争态势与公平竞争环境。

## 三、需求来源三级分类（用于子轮 B）

1. **法规强制**：法律、标准、许可、强制认证。
2. **合同/顾客要求**：合同、订单、CSR、顾客审核。
3. **隐含期望**：行业惯例、道德、声誉、可持续发展。

---

## 四、AI 推断原则

- 由「行业 + 产品 + 顾客定位」推导必查相关方（如汽车 → 顾客 + CSR + 供方 + 监管；出口 → 海关）。
- 由相关方类型推导常见需求（上表），并结合用户已给信息去重。
- 推断结果必须标注「AI 推断 · 待确认」，不得伪装成用户已确认事实。
- 不可遗漏：员工、股东/管理层、认证机构，这三类常被工程师忽略。
